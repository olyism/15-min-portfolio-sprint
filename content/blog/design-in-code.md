For years my process went sketch, Figma, prototype tool, handoff. Every step lost a little of the idea.

Now I sketch on paper, then ask an agent to scaffold the screen in the real stack. In an hour I can click through something that uses real data, real latency and real edge cases.

## What changed

- **I test behaviour, not pictures.** A prototype that loads real data shows problems a mock-up never will.
- **Handoff is a pull request.** Engineers review my branch instead of redrawing my frames.
- **I make more options.** When a variation costs ten minutes, I try five instead of one.

## What didn't

Figma is still where I think about layout, type and colour across many screens at once. Taste, judgment and knowing what to test are still my job.

## Try it

Pick one small, interactive thing you'd normally prototype. Describe it to an agent in plain words, run it locally, then refine it by talking to it. Hold on to the decisions, and let go of the typing.
