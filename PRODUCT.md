# Portfolio Sprint

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Designers learning to build a portfolio, including beginners in code. Visitors should find a relevant example across seven design specialties.

## Product Purpose
Demonstrate strong design stories and distinct project presentations that a designer can replace with their own work.

## Capabilities and Constraints
Existing Next.js App Router, React 19, TypeScript and Tailwind v4 repository. Content is Markdown and JSON. Retain the existing shared shell and use scoped project tokens. Seven fictional companies, specialties, problems and visual identities are explicitly requested. User delegated creative and implementation choices, including self-approval, while away. Do not interrupt for design choices.

## Evidence on Hand
All seven added projects are fictional teaching examples. No real research, clients, business metrics or production integrations were supplied. Local demo output is fixture-based and must be labelled accordingly.

## Brand Commitments
Keep the portfolio shell consistent. Make each project visually distinct and compelling. Use Impeccable guidance to avoid generic presentation. Content should explain decisions and trade-offs in plain language.

## Accessibility & Inclusion
Semantic HTML, keyboard access, visible focus, AA contrast, meaningful image alt text and reduced motion. Verify phone and desktop in light and dark themes.

## Independent project identities
The user requested a nested design-system page for every project (`/projects/<slug>/design-system`), drastically different project typography and look, and generated UI imagery grounded in similar real products. Generated artwork replaces the coded showcase specimens. Keep real local exercises separate from the static screenshots. Remove conceptual stamps from the artwork; retain one clear example-project disclosure in the story. Reference products are inspiration, not clients or affiliated products. Each project's identity and citations live in `content/project-worlds.json`.
