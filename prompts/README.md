# Prompts for chat-only AI tools

Using ChatGPT, Gemini or Claude.ai without a coding agent? Copy a prompt, paste in your material, then copy the result into the file it names.

Using Claude Code, Cursor or Codex? You don't need these. Open the project and say **"Set up my portfolio"**.

| Step | Prompt | Writes to |
|------|--------|-----------|
| 1 | [resume.md](resume.md) | `content/resume.json` |
| 2 | [design-system.md](design-system.md) | `app/tokens.css` (colours) + `content/voice.md` |
| 3 | [case-study.md](case-study.md) | `content/case-studies/<name>.md` |
| 4 | [image-generation.md](image-generation.md) | Images in `public/images/` |
